# Definition of Done Workflow

Используйте этот сценарий при завершении любого этапа, фичи или исправления бага в PhotoCraft Plugins & Companion.

## Шаг 1. Тестирование с ограничением ресурсов
Выполните запуск всех тестов в режиме строгого Resource Guard:
```powershell
cargo test --workspace -j 1
```
*Убедитесь, что все тесты во всех крейтах (`core_contracts`, `photocraft_bridge`, `ai_engine`, `overlay_ui`, `companion_app`, `plugin_validator`) завершились с успехом.*

## Шаг 2. Валидация каталога плагинов
```powershell
cargo run --package plugin_validator -j 1 -- --validate plugins
```

## Шаг 3. Фиксация дефектов в баг-трекере
Если в процессе работы был выявлен или исправлен дефект:
1. Откройте `docs/BUGS_AND_ISSUES.md`.
2. Зарегистрируйте строку с кодом `BUG-XXX` или переведите существующий в `RESOLVED`, заполнив причину и решение.

## Шаг 4. Актуализация чек-листа
Откройте `docs/CHECKLIST.md` и переведите завершенные пункты в состояние `[x]`.

## Шаг 5. Синхронная запись летописи
1. Откройте `docs/CHRONICLE.md` (русская версия). Добавьте авторскую запись с указанием времени: `*Время: ДД месяца ГГГГ, ЧЧ:ММ (~ХХ минут)*`.
2. Откройте `docs/CHRONICLE.en.md` (английская версия). Добавьте синхронный перевод записи.
