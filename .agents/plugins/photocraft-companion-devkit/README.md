# PhotoCraft Companion DevKit (Antigravity Plugin)

Официальный плагин для Google Antigravity, автоматизирующий работу над проектом **PhotoCraft Plugins & Companion**.

## Возможности плагина:
* **Resource Guard:** Защита от перегрузки ПК — принудительный запуск `cargo` только с флагом `-j 1`.
* **Definition of Done Guard:** Контроль 100% прохождения тестов, линтера локализации `i18n_lint_test`, актуализации чек-листа, баг-трекера `BUG-XXX` и двуязычной авторской хроники.
* **Zero-Core Hardcoding:** Полный запрет модификации ядра под логику плагинов.
* **Vector-First UI:** Защита от глифов-квадратиков «тофу» (`□`) и эмодзи в интерфейсе `egui`.
* **Zero-Yesman Principle:** Обязательное предварительное исследование сомнительных идей в сети и аргументированное предупреждение разработчика.
* **Параллельная оркестрация:** Готовые субагенты (`bridge-specialist`, `ai-specialist`, `ui-specialist`, `chronicle-writer`, `quality-auditor`) для параллельного выполнения задач с чистым основным контекстом.
