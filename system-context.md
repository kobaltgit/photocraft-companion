# System Context — PhotoCraft Plugins & Companion

## Проблема
Редактор **PhotoCraft** — современный, быстрый растровый редактор на Rust, воспроизводящий интерфейс и возможности Photoshop. Однако его встроенная плагинная система на WebAssembly (Wasm ABI v1) принципиально изолирована от операционной системы: модули не имеют доступа к GPU, сети, файлам и ограничены 32 МБ. В результате внутри PhotoCraft невозможно запустить тяжёлые локальные ИИ-модели (например, студийное удаление фона, апскейлеры, Inpainting) или добавить кастомные системные действия.

## Решение
Проект **PhotoCraft Plugins & Companion** предоставляет внешнюю архитектуру расширений:
1. **PhotoCraft Bridge:** связь с запущенным окном редактора через его официальный Control Channel (порт 18492) в реальном времени.
2. **AI Engine:** запуск локальных нейросетей (RMBG-1.4 / BiRefNet) через ONNX Runtime с использованием GPU/DirectML/CPU.
3. **Seamless In-Place Execution:** автоматический перенос обработанных слоёв/масок обратно в холст через буфер обмена или API документа без промежуточных файловых диалогов.
4. **Docked Overlay Toolstrip:** элегантная плавающая или прилипающая к окну PhotoCraft панель с кнопками, эмулирующими вызов функций и хоткеев, с возможностью лёгкого добавления новых кнопок через конфигурационный файл.
