# PhotoCraft Plugins — Antigravity Rules

1. **Context7 First:** Всегда запрашивать актуальную документацию для API (`onnxruntime`, PhotoCraft control protocol, Win32 GUI).
2. **Contract-First:** Пакеты не должны напрямую зависеть друг от друга; связь только через `packages/core_contracts`.
3. **Бесшовность пользовательского опыта:** Никаких лишних ручных шагов для пользователя — всё должно применяться прямо в открытом окне PhotoCraft.
4. **Фиксация в доках:**
   - Баги -> `docs/BUGS_AND_ISSUES.md`.
   - Прогресс -> `docs/CHECKLIST.md`.
   - Хроника -> `docs/CHRONICLE.md` и `docs/CHRONICLE.en.md` (синхронно, с метками времени).
5. **Запрет завершения без тестов и актуальных доков (Definition of Done):**
   - **СТРОГО ЗАПРЕЩЕНО** считать любой этап/задачу завершенной без:
     - 100% прохождения всех тестов воркспейса (`cargo test --workspace`);
     - Приведения в актуальное состояние всей проектной документации (`CHECKLIST.md`, `BUGS_AND_ISSUES.md`, `CHRONICLE.md`, `CHRONICLE.en.md`).
6. **Железное ограничение ресурсов при компиляции (Resource Guard):**
   - **СТРОГО ЗАПРЕЩЕНО** вызывать любые команды `cargo build`, `cargo check`, `cargo test`, `cargo clippy` без жесткого ограничения потоков (`-j 1`, максимум `-j 2`).
   - Никогда не перегружать CPU и RAM рабочей станции пользователя! В `.cargo/config.toml` зафиксированы `jobs = 1` и `codegen-units = 1`.
7. **ЖЕЛЕЗНЫЙ ЗАПРЕТ ХАРДКОДА ПОД ПЛАГИНЫ (Strict Zero-Core Hardcoding Prohibition):**
   - **СТРОГО ЗАПРЕЩЕНО** модифицировать исходный код программы (`companion_app`, `ai_engine`, `photocraft_bridge`) под логику конкретных плагинов (писать специальные условия под ID плагинов, вшивать `image.revealAll`, `layer.mergeDown` и специфичные шаги в Rust-код движка).
   - **АБСОЛЮТНЫЙ ЗАКОН:** Любой сторонний пользователь или разработчик должен иметь возможность написать плагин (положить файл `.onnx` и декларативный манифест `plugin.json` в папку `plugins/`) — и он **ОБЯЗАН РАБОТАТЬ СРАЗУ, БЕЗ ИЗМЕНЕНИЯ КОДА ПРОГРАММЫ И БЕЗ ЕЁ ПЕРЕСБОРКИ**.
   - Все параметры (источник входа, задача нейросети, команды до и после инференса `post_commands`, способ наложения результата) задаются **ИСКЛЮЧИТЕЛЬНО В MANIFEST `plugin.json`**. Ядро — это лишь нейтральный универсальный рантайм.
