# Руководство по установке и первому запуску PhotoCraft Companion (First-Run & Installation Guide)

PhotoCraft Companion (версия v1.2.2+) — официальная плавающая оверлей-панель для графического редактора PhotoCraft.
В данном руководстве подробно описаны доступные дистрибутивы, особенности установки и решение типовых проблем первого запуска на Windows, macOS и Linux.

---

## 📦 Доступные дистрибутивы и пакеты

Для всех поддерживаемых операционных систем проект предоставляет **два формата дистрибутивов**:

1. **Официальные системные установщики (Рекомендуется):**
   - 🪟 **Windows x64:** `PhotoCraft-Companion-Setup-Windows-x64.exe` (Inno Setup) — устанавливает приложение, создает ярлыки в меню «Пуск» и на рабочем столе, регистрирует программу для автозапуска.
   - 🍏 **macOS (Apple Silicon & Intel):** `PhotoCraft-Companion-Setup-macOS.dmg` — стандартный образ диска для перетаскивания `PhotoCraft Companion.app` в папку `/Applications`.
   - 🐧 **Linux (x86_64):** `photocraft-companion_1.2.2_amd64.deb` — системный DEB-пакет для Ubuntu, Debian, Linux Mint, Astra Linux с интеграцией в меню приложений.

2. **Портативные архивы (Portable):**
   - 🪟 **Windows x64:** `PhotoCraft-Companion-v1.2.2-windows-x64-portable.zip` — распакуйте в любую удобную папку и запускайте без установки.
   - 🍏 **macOS:** `photocraft-companion-v1.2.2-macos-portable.tar.gz` — портативный бандл.
   - 🐧 **Linux:** `photocraft-companion-v1.2.2-linux-x64-portable.tar.gz` — универсальный архив для любых дистрибутивов Linux (Arch, Fedora, openSUSE и др.).

> ℹ️ **Почему системы выдают предупреждения безопасности?**
> PhotoCraft и PhotoCraft Companion — это свободные проекты с открытым исходным кодом (Open Source). Покупка коммерческого сертификата цифровой подписи (EV Code Signing от Microsoft / Apple Developer ID) стоит сотни долларов в год. Поэтому встроенные фильтры ОС (Windows SmartScreen, Apple Gatekeeper) предупреждают о «неизвестном издателе». Это штатное поведение для независимого ПО.

## 🪟 Windows: Инструкция по первому запуску и обход SmartScreen

### 1. Предупреждение Windows SmartScreen
При первом запуске установщика или портативного `.exe` файла Windows может отобразить синий экран:
*«Система Windows защитила ваш компьютер. Фильтр Windows SmartScreen предотвратил запуск неопознанного приложения...»*

**Решение:**
1. В синем окне нажмите на текстовую ссылку **«Подробнее» (More info)**.
2. В правом нижнем углу появится кнопка **«Выполнить в любом случае» (Run anyway)** — нажмите её.
3. Программа успешно запустится. При последующих запусках предупреждение больше не появится.

### 2. Запрос сетевого экрана (Брандмауэр Windows)
PhotoCraft Companion общается с редактором PhotoCraft по локальному сокету `127.0.0.1:18492`.
При первом запуске брандмауэр Windows может спросить разрешение на сетевой доступ.
- **Действие:** Установите флажок напротив **«Частные сети» (Private networks)** и нажмите **«Разрешить доступ»**.

### 3. Окно «PhotoCraft запущен без сокета»
Если PhotoCraft запущен пользователем вручную без специального параметра связи, Компаньон покажет окно оффлайн-онбординга.
- **Решение:** Нажмите кнопку **`> Запустить PhotoCraft`** внутри окна Компаньона. Компаньон автоматически запустит редактор с нужным портом и токеном авторизации.

## 🍏 macOS: Первый запуск и обход Apple Gatekeeper

В macOS встроенная подсистема безопасности Gatekeeper блокирует неподписанные приложения из интернета («Приложение повреждено», «Не удается открыть из-за неустановленного разработчика» или тихо завершает процесс `Killed: 9`).

### Способ 1: Открытие через «Правый клик» (Самый простой)
1. Установите приложение, перетащив `PhotoCraft Companion.app` в папку `/Applications`.
2. Зажмите клавишу **Control** и кликните по иконке приложения (либо нажмите правой кнопкой мыши).
3. В контекстном меню выберите пункт **«Открыть» (Open)**.
4. В появившемся диалоговом окне появится дополнительная кнопка **«Открыть»**. Нажмите её.
5. macOS запомнит ваш выбор и в будущем приложение будет открываться обычным двойным кликом.

### Способ 2: Через Системные настройки
1. Если при двойном клике появилось окно о блокировке, нажмите «Отмена».
2. Откройте **«Системные настройки» (System Settings) -> «Конфиденциальность и безопасность» (Privacy & Security)**.
3. Прокрутите вниз до раздела **«Безопасность» (Security)**.
4. Там появится сообщение: *«Приложение "PhotoCraft Companion" было заблокировано, так как оно создано неизвестным разработчиком»*.
5. Нажмите кнопку **«Подтвердить вход» (Open Anyway)** и введите пароль администратора.

### Способ 3: Снятие карантинного атрибута через Терминал (Гарантированный фикс)
Если Gatekeeper продолжает блокировать запуск, откройте Терминал и выполните команду снятия атрибута карантина:
```bash
xattr -cr "/Applications/PhotoCraft Companion.app"
```
После этого приложение запустится штатно.

> 🔒 **Защита целостности CodeSeal:** В версии v1.2.2 файл `control.token` автоматически сохраняется в стандартную системную папку `~/Library/Application Support/PhotoCraft/` и никогда не пишется внутрь бандла `.app`, предотвращая повреждение подписи.

## 🐧 Linux: Установка .deb пакета и запуск Portable версии

### Вариант 1: Установка DEB-пакета (Ubuntu, Debian, Mint)
Рекомендуемый способ. Установщик автоматически настраивает права доступа и добавляет ярлык в меню приложений.
```bash
sudo dpkg -i photocraft-companion_1.2.2_amd64.deb
```
Если требуются недостающие системные библиотеки:
```bash
sudo apt install -f -y
```

### Вариант 2: Использование Portable архива (.tar.gz)
При распаковке архива файлы могут потерять флаг исполнения.
1. Распакуйте архив и перейдите в папку:
   ```bash
   tar -xzf photocraft-companion-v1.2.2-linux-x64-portable.tar.gz
   cd photocraft-companion
   ```
2. Сделайте бинарный файл исполняемым:
   ```bash
   chmod +x photocraft-companion
   ```
3. Запустите программу:
   ```bash
   ./photocraft-companion
   ```

### Необходимые системные библиотеки на Linux
Для рендеринга GUI (egui/winit) и сетевого моста требуются стандартные библиотеки:
```bash
sudo apt install -y libssl-dev libfontconfig1 libx11-xcb1
```

### Решение проблем с графическим сервером Wayland
Если в современных дистрибутивах (GNOME/KDE на Wayland) плавающий тулбар отображается некорректно, запустите Компаньон с принудительным использованием бэкенда X11 (XWayland):
```bash
WINIT_UNIX_BACKEND=x11 ./photocraft-companion
```

## 🔌 Подключение к PhotoCraft и сокет 18492

PhotoCraft Companion работает в связке с редактором PhotoCraft по локальному протоколу JSON-RPC:
- **Порт:** `18492` (локальный loopback `127.0.0.1`).
- **Авторизация:** Безопасный токен `control.token`, генерируемый автоматически.
- **Автопоиск редактора:** При нажатии кнопки `> Launch PhotoCraft` Компаньон автоматически ищет исполняемый файл в стандартных системных директориях:
  - Windows: в текущей директории, `../PhotoCraft/` и системных путях;
  - macOS: `/Applications/PhotoCraft.app` и `~/Downloads/PhotoCraft.app`;
  - Linux: `/usr/bin/photocraft` и локальные каталоги.
- **Ручная настройка пути:** Если PhotoCraft установлен в нестандартной папке, откройте Менеджер плагинов (**кнопка шестеренки `⚙` -> вкладка `Connection`**), укажите точный путь к файлу PhotoCraft и нажмите `> Launch`. В версии v1.2.2 настройки сохраняются автоматически!
