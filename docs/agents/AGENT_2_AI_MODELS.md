# Инструкция: Агент 2 (AI Models Team)

**Зона ответственности:** `crates/ai_engine/`

### Задачи:
1. Загрузка и инференс ONNX-моделей (RMBG-1.4, BiRefNet, исправление границ) через `onnxruntime`.
2. Поддержка аппаратных провайдеров (DirectML для RTX 4060, CPU fallback).
3. Препроцессинг (ресайз, нормализация тензоров) и постпроцессинг (альфа-маттинг, восстановление оригинального разрешения).
4. Экспорт прозрачных RGBA-изображений и 8-битных альфа-масок.
