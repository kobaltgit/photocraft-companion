# Инструкция: Агент 1 (PhotoCraft Bridge Team)

**Зона ответственности:** `crates/photocraft_bridge/`

### Задачи:
1. Поддержание надёжного TCP/JSON-RPC соединения с сокетом управления PhotoCraft (порт 18492).
2. Реализация методов получения текущего документа, активного слоя, его размеров и пиксельных данных.
3. Реализация методов обратной записи: бесшовная вставка вырезанного объекта обратно в документ через кроссплатформенный буфер обмена (Windows, macOS, Linux, BSD) или команду `edit.paste` / `edit.pasteInPlace`.
4. Обработка обрывов соединений и автоматическое переподключение.
