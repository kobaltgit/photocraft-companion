# Инструкция: Агент 3 (Overlay UI & Hotkeys Team)

**Зона ответственности:** `crates/overlay_ui/` и `crates/hotkey_service/`

### Задачи:
1. Создание легковесной панели инструментов (Toolstrip/Overlay), визуально привязывающейся к координатам окна PhotoCraft.
2. Поддержка тёмной темы в тон PhotoCraft (`#1e1e1e` / `#282828`).
3. Динамическая загрузка кнопок из конфигурационного файла `buttons.json`.
4. Диспетчеризация нажатий кнопок: запуск плагина (`remove_bg`) или посылка хоткея в PhotoCraft.
5. Глобальный и контекстный перехват горячих клавиш.
