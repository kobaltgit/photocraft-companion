# Спецификация интерфейса, плавающей панели и системы плагинов PhotoCraft

> **Дата утверждения:** 11 октября 2026  
> **Статус:** Утверждено в разработку  
> **Основа дизайна:** Референс окна настроек *«PeekIt Preferences»* в фирменных цветах и геометрии *PhotoCraft*  

---

## 1. Концепция и ключевые изменения

В ходе совместного проектирования и анализа первых прототипов утверждены фундаментальные принципы:
1. **Отказ от сырого блочного макета:** Переход от перегруженных карточек с огромными отступами к выверенному десктопному интерфейсу по эталону окна настроек (*PeekIt Preferences*).
2. **Строгая палитра PhotoCraft:** Графитовый фон (`#242424`), слегка затемнённые вложенные карточки-группы (`#1e1e1e`), тонкие разделители и рамки (`#3e3e3e`), скругления 8–10 px, фирменный синий акцент (`#2a82e4`).
3. **Чистый десктопный стиль:** Полное исключение цветных эмодзи в UI и меню Windows — только читаемый векторный монохром, четкие шрифты и пиктограммы.
4. **Единый контур тем (Dark / Light / System):** Синхронное переключение темы во всем приложении (плавающая панель, окно менеджера и нативное контекстное меню трея через Win32 API).

## 2. Плавающая панель инструментов (Floating Toolstrip)

### 2.1. Геометрия и позиционирование
* **Форм-фактор:** Безрамочное окно без системного заголовка Windows (`decorations: false`, `always_on_top`).
* **Зона появления по умолчанию:** 
  * Определяется автоматически по координатам окна PhotoCraft через Win32 API (`GetWindowRect`).
  * Позиционируется в **горизонтальной свободной зоне** над холстом справа:
    * По вертикали: сразу под панелью параметров / вкладками документа (~75 px от верха окна PhotoCraft).
    * По горизонтали: прямо перед правым блоком док-панелей (Color, Properties, Layers) с отступом слева от них.
* **Свободное перетаскивание:** 
  * В левой части панели располагается аккуратная ручка захвата (Drag Handle) с точечным паттерном.
  * Панель можно ухватить мышью и перетащить в любое место экрана.
* **Переключение ориентации:**
  * В шапке панели присутствует кнопка смены ориентации (`⇄` / `⇅`).
  * По умолчанию — **горизонтальная**.
  * По клику переключается в **вертикальный столбик** (в стиле левой панели инструментов PhotoCraft) с плавным пересчетом размера окна.
* **Динамический размер (Dynamic Sizing):**
  * Габариты панели не фиксированы, а рассчитываются по числу активных кнопок:
    * *Горизонтальный режим:* высота `44 px`, ширина = `(активных_кнопок * 38 px) + 80 px (служебные кнопки)`.
    * *Вертикальный режим:* ширина `46 px`, высота = `(активных_кнопок * 38 px) + 40 px (служебные кнопки)`.
  * При установке нового плагина или включении/выключении кнопки панель автоматически подстраивает размер.

### 2.2. Кнопки действий
* **Размер кнопок:** 32×32 px (комфортно помещаются в высоту 44 px без срезания краев).
* **Индикация:** Индивидуальные иконки плагинов (SVG/растр) с лаконичными текстовыми бейджами (`AI`, `BW`, `CP`, `PS`).
* **Всплывающие подсказки:** При наведении выводится тултип с полным названием инструмента и назначенным хоткеем (например, *«AI Remove Background (Ctrl+Shift+B)»*).
* **Служебные элементы:**
  * Кнопка шестеренки `⚙` — открывает Менеджер плагинов.
  * Кнопка сворачивания `—` — скрывает панель в системный трей.
* **Исполнение команд:** Клик по кнопке мгновенно отправляет асинхронную команду в PhotoCraft через `tokio::spawn` с обработкой результата.

## 3. Менеджер плагинов (Plugin Manager)

Окно настроек полностью базируется на эталоне *PeekIt Preferences*:

```text
+--------------------------------------------------------------------------+
| ⚙ PhotoCraft Companion Settings                                        ✕ |
+--------------------------------------------------------------------------+
| [ General ]      [ Plugins ]      [ Hotkeys ]      [ About ]             |
+--------------------------------------------------------------------------+
|                                                                          |
|   (Контент активной вкладки в закругленной темной карточке-группе)       |
|                                                                          |
|                                                                          |
|                                                                          |
+--------------------------------------------------------------------------+
|                                                         [ Close ] [ Save ]|
+--------------------------------------------------------------------------+
```

### 3.1. Структура вкладок
1. **Вкладка `[ General ]` (Общие настройки):**
   * **Language (Язык интерфейса):** Выпадающий список (`English (EN)` / `Русский (RU)`).
   * **Theme (Тема оформления):** Строго 3 варианта в выпадающем списке:
     * `Dark` (Тёмная — графитовая классика PhotoCraft)
     * `Light` (Светлая — лаконичная нейтральная палитра)
     * `System` (Системная — чтение `AppsUseLightTheme` из реестра Windows)
   * **Connection (Параметры связи):** Хост, порт (18492), токен управления и кнопка *«Auto-Detect Token»*.
2. **Вкладка `[ Plugins ]` (Управление расширениями):**
   * Кнопка **`[ + Установить плагин (.pcpl) ]`** в верхней части для добавления новых пакетов через проводник Windows.
   * Список установленных плагинов в виде компактных строк внутри карточки:
     * Чекбокс включения/выключения на панели.
     * Цветной тип-бейдж (`AI GPU`, `NO-CODE`, `SCRIPT`, `CLI`).
     * Название, версия, автор, описание.
     * Назначенный хоткей.
3. **Вкладка `[ Hotkeys ]` (Горячие клавиши):**
   * Таблица действий и текущих комбинаций клавиш с возможностью изменения и защиты от системных конфликтов.
4. **Вкладка `[ About ]` (О программе):**
   * Название, версия компаньона.
   * Архитектура стека: Rust Cargo Workspace, DirectML GPU Hardware Acceleration, egui/eframe.
   * Лицензия, авторство и ссылки на документацию.

### 3.2. Нижняя панель действий
* Справа внизу располагаются кнопки:
  * **`[ Close ]`** — закрыть окно настроек без сохранения несохраненных правок.
  * **`[ Save ]`** — применить параметры, сохранить `preferences.json` / `companion_config.json` и обновить плавающую панель.

## 4. Формат плагинов `.pcpl` (PhotoCraft Plugin Package)

Для простоты распространения и установки утвержден формат **`.pcpl`**:
* **Физический формат:** Стандартный ZIP-архив с расширением `.pcpl`.
* **Внутренняя структура пакета:**
  ```text
  my_cool_plugin.pcpl
  ├── plugin.json       # Обязательный манифест плагина
  ├── icon.svg          # Векторная иконка для кнопки тулбара (или icon.png)
  ├── models/           # Папка с ONNX-весами нейросети (если плагин типа native_ai)
  └── scripts/          # Скрипты автоматизации (если плагин типа script)
  ```
* **Манифест `plugin.json`:**
  ```json
  {
    "id": "photocraft.plugins.watermark",
    "name": "Add Watermark",
    "version": "1.0.0",
    "author": "PhotoCraft Community",
    "plugin_type": "no_code",
    "default_hotkey": "Ctrl+Shift+W",
    "icon": "icon.svg",
    "description": "Places branding watermark layer on top.",
    "pipeline": [
      { "action": "layer.new", "params": { "name": "Watermark" } }
    ]
  }
  ```
* **Процесс установки:**
  1. Пользователь нажимает `[ + Установить плагин (.pcpl) ]` в Менеджере.
  2. В проводнике выбирается файл `*.pcpl`.
  3. Пакет распаковывается в папку `plugins/<id>/`.
  4. Реестр `PluginRegistry` мгновенно регистрирует плагин.
  5. Плавающая панель динамически увеличивает ширину и добавляет новую кнопку.

## 5. Поведение при незапущенном PhotoCraft (Offline / Waiting)

* Если компаньон запущен, а PhotoCraft закрыт:
  * Компаньон не завершает работу с ошибкой.
  * Отображается аккуратное окно-уведомление в графитовом стиле:
    * Заголовок: *PhotoCraft не обнаружен*
    * Сообщение: *«Пожалуйста, запустите PhotoCraft, чтобы панель инструментов и плагины активировались.»*
    * Индикатор фонового ожидания: проверка доступности сокета раз в 1.5 секунды.
    * Кнопка: `[ Открыть Менеджер плагинов ]` (позволяет настраивать хоткеи и устанавливать `.pcpl` даже без запущенного редактора).
  * Как только PhotoCraft запускается — окно ожидания автоматически скрывается, а панель инструментов появляется в заданной верхней зоне над холстом.

## 6. Системный трей и интеграция с Windows

1. **Векторные иконки автора:**
   * Растеризация файлов `assets/icon-dark.svg` и `assets/icon_light.svg` через `resvg` прямо в память (32×32 для трея, 64×64 для окон).
2. **Тёмная тема контекстного меню Win32:**
   * Вызов `uxtheme::SetPreferredAppMode` подстраивает цвет фона системного меню Windows под выбранную тему (тёмный в Dark, светлый в Light).
3. **Состав меню трея:**
   * `PhotoCraft Toolbar` (показать/скрыть плавающую панель)
   * `Plugins Manager` (открыть окно настроек)
   * `----------------`
   * `Exit Companion` (завершение работы)
4. **Обработка событий трея:**
   * Опрос `tray_icon::menu::MenuEvent` встроен в главный цикл обновления кадра `eframe::App`, обеспечивая мгновенный отклик на клики в меню.
