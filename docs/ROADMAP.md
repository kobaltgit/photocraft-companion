# Дорожная карта (Roadmap)

## Milestone 1: MVP In-Place Remove-BG (Завершено ✅)
* **Цель:** Мгновенное удаление фона активного слоя прямо в открытом окне PhotoCraft.
* **Результат:** 
  - Нативный клиент сокета управления PhotoCraft (JSON-RPC поверх TCP, порт 18492).
  - Сквозной обмен пикселями через память и буфер обмена (`arboard`) без временных файлов.
  - Нативный инференс RMBG-1.4 через ONNX Runtime (`ort 2.0.0-rc.13`).
  - Успешная боевая проверка на 8K-холсте (8256×4608) с сохранением геометрии.
  - Автоматическое восстановление соединения (auto-reconnect) при разрывах сокета.

## Milestone 2: Умное именование, i18n и аппаратное ускорение GPU (Текущий 🚀)
* **Цель:** Идеальная чистота слоёв, поддержка языков PhotoCraft и ускорение нейросетей на видеокартах.
* **Результат:**
  - Сохранение пользовательского имени слоя с добавлением локализованного суффикса (например, `Имя (No BG)` / `Имя (Без фона)`).
  - Модуль локализации `i18n` с поддержкой всех языков PhotoCraft (`auto`, `en`, `ru`, `de`, `fr`, `es`, `it`, `ja`, `zh`, `ko`, `pt`).
  - Автовыбор оборудования в `ai_engine`: DirectML (NVIDIA RTX, AMD Radeon, Intel Arc / Iris Xe) с безопасным откатом на CPU.
  - Асинхронная изоляция инференса через `spawn_blocking`.

## Milestone 3: Архитектура плагинов и открытый SDK (Plugin Ecosystem)
* **Цель:** Возможность для любого стороннего разработчика легко создавать плагины для PhotoCraft.
* **Результат:**
  - Трейт `Plugin` и богатый интерфейс `PluginContext` (доступ к 851 команде PhotoCraft, маскам, слоям, пикселям, UI-статусам и AI-инференсу).
  - Два формата плагинов:
    1. Декларативные (No-Code `plugin.json` для макросов и сторонних CLI-утилит);
    2. Нативные Rust-плагины (`photocraft_plugin_sdk`).
  - Автоматическое сканирование каталога `plugins/*/plugin.json`.

## Milestone 4: Floating Overlay Toolstrip и GUI Менеджер плагинов
* **Цель:** Плавающая плашка кнопок над PhotoCraft и единое окно управления плагинами.
* **Результат:**
  - Компактный Toolstrip на `egui` / `eframe` в тёмной теме PhotoCraft (`#1e1e1e` / `#282828`).
  - Окно **Plugin Manager**: включение/отключение плагинов тумблерами, настройка хоткеев, порядок кнопок.
  - Окно настроек подключения: хост, порт, ввод/автопоиск токена, выбор языка и GPU.

## Milestone 5: Системный трей и расширенный каталог AI-инструментов (Завершено ✅)
* **Цель:** Полноценный фоновый сервис и новые нейросетевые инструменты.
* **Результат:**
  - Иконка в системном трее Windows/Linux/macOS с реактивным меню без задержек.
  - Автономный плагин `remove_bg` с локальными весами `rmbg-1.4.onnx` и пакетирование `.pcpl`.

## Milestone 6: Универсальное ядро плагинов (Universal Plugin Core) (Специфицировано 📋)
* **Цель:** Превращение ядра в универсальный раннер для любых типов плагинов сторонних авторов.
* **Спецификация:** [`docs/UNIVERSAL_PLUGIN_CORE_SPECIFICATION.md`](file:///d:/Projects/active/photocraft-plugins/docs/UNIVERSAL_PLUGIN_CORE_SPECIFICATION.md)
* **Планируемый результат:**
  - **Embedded Rhai Scripts (`plugin_type: "script"`):** Легковесная автоматизация на чистом Rust без C-компиляторов (`plugin.rhai`). Доступ к командам и геометрии слоев.
  - **External CLI Process Runner (`plugin_type: "external_cli"`):** Запуск внешних бинарников (Python, ImageMagick, Go, C++) через `tokio::process::Command` с режимами `JsonArgs`, `StdinStdout`, `TempFileInPlace`.
  - **C-ABI Dynamic Libraries (`plugin_type: "dynamic_lib"`):** Динамическая загрузка библиотек (`.dll` / `.so` / `.dylib`) через `libloading` со стабильной структурой `PhotoCraftContextC` и вызовом `photocraft_plugin_execute`.
  - Полная поддержка всех форматов в установщике пакетов `.pcpl` через диалог Менеджера плагинов.

## Milestone 7: Полная декларативность ИИ-пайплайнов и запрет хардкода ядра (Zero-Core Contract Standard) (Текущий 🚀)
* **Цель:** Исключить любое вмешательство в исходный код компаньона при создании и установке новых ИИ-плагинов сторонними разработчиками.
* **Результат:**
  - **Железный запрет хардкода:** Строгий запрет модификации кода ядра (`companion_app`, `ai_engine`, `photocraft_bridge`) под логику конкретных плагинов.
  - **Декларативный пайплайн в манифесте:** Все параметры рабочего процесса плагина (источник входа: активный слой/выделение/холст; задача ИИ; пред- и пост-команды `commands` / `post_commands`: `image.revealAll`, `layer.mergeDown` и др.; режим наложения `in_place` / `new_layer`) задаются исключительно в `plugin.json`.
  - **Универсальный рантайм `GenericAiPlugin`:** Движок исполняет цепочки команд из манифеста, гарантируя, что любой пользователь может положить новую модель `.onnx` и `plugin.json` (или `.pcpl`), и плагин заработает моментально без компиляции.
