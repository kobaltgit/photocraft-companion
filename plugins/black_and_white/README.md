# B&W Film Pop (No-Code Macro)

[![Plugin: B&W Film Pop](https://img.shields.io/badge/Plugin-B%26W_Film_Pop-blue.svg)](plugin.json)
[![Type: No-Code Macro](https://img.shields.io/badge/Type-No--Code_Macro-orange.svg)](plugin.json)

**English:**
Lightweight zero-code macro plugin for PhotoCraft.
Safely duplicates the active layer (`layer.duplicate`) and converts it to a classic high-contrast monochrome film look (`image.adjustments.desaturate`) in a single click, preserving the original layer intact beneath.

### Use Cases:
- **Instant Noir & Monochrome Aesthetics:** One-click conversion of color street and portrait photography into timeless black-and-white.
- **Non-Destructive Value Checking:** Quick grayscale contrast and tonal value checking for digital painters to verify scene lighting balance.

---

**Русский:**
Легковесный декларативный No-Code макро-плагин для PhotoCraft.
В один клик дублирует активный слой (`layer.duplicate`) и обесцвечивает его (`image.adjustments.desaturate`), сохраняя оригинальный цветной слой нетронутым снизу.

### Практическое применение:
- **Черно-белая художественная фотография:** Мгновенный перевод стрит- и портретных фото в монохромный стиль пленочного нуара.
- **Проверка тонального баланса:** Быстрый неразрушающий контроль контраста и светотени для цифровых художников при рисовании концепт-артов в PhotoCraft.
